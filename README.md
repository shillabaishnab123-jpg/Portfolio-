Trial portfolio website.

- style.css — design and responsive layout
- script.js — mobile navigation
- images/shilla-portrait.png — profile image
- images/mind-map.png — personal mind map

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder so `index.html` is in the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Open the generated GitHub Pages URL.
